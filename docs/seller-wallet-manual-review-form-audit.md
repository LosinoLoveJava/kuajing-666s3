# 商家钱包充值、提款改为人工审核资料

## 需求和行为

商家在 SWIFT / BIC 填写 `123` 时，原服务端正则会阻止提交。根据用户确认，商家充值和提款的银行资料不再强制格式或必填，由人工审核资料，金额继续严格校验。

商家的持有人、银行名称、账号、国家、IBAN、SWIFT / BIC 均可自由填写或留空，国家改为文本输入，不再局限 IBAN 国家列表。充值交易流水号也改为选填。资料不再自动修改大小写或 IBAN 格式；仍保留字符串类型和存储长度限制（银行字段 2000 字符、流水号 200 字符）。共享提款模板通过 `manualReview` 参数启用商家模式，买家原有校验继续保留。

充值表单新增隐藏请求令牌，未填流水号时按商家与令牌防重复；已填流水号时继续按商家与流水号防重复。充值始终待审，审核通过才入账。提款保留余额校验、待审核限制、提交即预留款项、驳回退款及审核防重复机制。

## 金额规则

- 仅允许正数和最多两位小数，拒绝负数、零、科学计数法及过大输入。
- 提款以 USD 为准，至少 0.01 USD，金额不能超过可用余额。
- 当前充值表单输入 AED，至少 0.02 AED；服务器按 `1 USD = 3.67 AED` 使用 BCMath 换算并四舍五入至美分。客户端隐藏 USD 不参与金额校验或记账依据。
- 审核沿用已保存申请金额，不接受客户端篡改审核金额，不重复入账、扣款或退款。
