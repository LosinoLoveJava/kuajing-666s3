# 管理端钱包、佣金和产品仓库显示修复

日期：2026-10-23。

## 诊断与修复

涉及 `/admin/wallet-history`、`/admin/commission-log`、`/admin/product/storehouse`。

诊断时三个默认线上列表能够返回数据，未持续复现用户描述的仓库空白。确认存在两个缺陷：报表结束日期使用当天零点作为上界，会排除当天非零点记录；`.aiz-table` 默认透明且高度为零，脚本未成功初始化时记录不可见。

- 日期筛选改为包含开始日期、排除结束日期次日零点，校验日期格式和先后顺序。
- 服务端表格默认可见，增加明确的横向滚动容器、空结果提示、筛选错误和清除入口；管理端 CSS 更新版本参数。
- 钱包、佣金分页保留筛选条件，排序增加 ID 以稳定分页；预加载关联用户、订单和库存。
- 仓库名称/SKU 搜索条件分组，防止 SKU 匹配绕过仓库、产品类型和归属限制；排序限定为页面支持的选项。
- 钱包审批拒绝状态正确显示；共享佣金入口限制卖家只能查询自己，并修正卖家模板路径。
