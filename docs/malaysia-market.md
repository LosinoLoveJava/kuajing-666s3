# 马来西亚充值、提款与短信认证

法币充值、提款使用 MYR，初始汇率为 **1 USD = 4.17 MYR**。充值金额除以 4.17 入账 USD，提款 USD 乘以 4.17 预估 MYR，均按分四舍五入。充值仍需后台审核；提款保留提交时的收款资料及汇率快照。历史土耳其、新加坡记录继续显示其原始国家、币种及汇率。

充值和提款均必填持户人姓名、银行名称、银行账户号码；马来西亚银行账户不使用 IBAN。账户号码按字符串保存，保留前导零。加密货币流程保持现有规则。

手机注册、登录、找回密码和商家注册统一使用马来西亚 `+60`。支持 `0123456789`、`123456789`、`60123456789`、`+60 12-345 6789`、`0060123456789`，以及 `011` 的长号段。短信复用既有 Chuanx 通道及 `CHUANX_SMS_*` 环境配置，接口提交 `60` 开头的号码；实际送达需通道支持马来西亚。自动化测试模拟网关响应，不发送收费短信。

本地数据库已导入时运行 `deploy/apply-local-malaysia.php`；正常本地启动也会在数据库同步后自动应用该迁移。
