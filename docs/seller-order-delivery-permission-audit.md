# 商家订单邮寄状态改为总管理端维护

## 行为和权限

商家管理端的订单详情页使用只读输入框展示邮寄状态，并提示“邮寄状态仅可由总管理端修改。”；不再渲染状态下拉框和更新状态的 AJAX。无论 `product_manage_by_admin` 配置如何，商家均可查看状态。

商家更新接口保留路由但固定返回 HTTP 403，避免缓存旧页面或直接构造请求绕过。总管理端和旧通用路径共用的状态处理方法在读取订单、执行任何副作用前检查身份，仅允许 `admin`、`staff`。配送 API 的状态修改入口同样返回 403，状态变更统一由总管理端操作。付款和提货操作保持原有逻辑。

## 隔离测试

新增 `tests/Feature/SellerOrderDeliveryPermissionTest.php`：17 项测试、279 次断言通过。覆盖商家六种状态、本人/其他商家/不存在订单、四条更新路径均拒绝；订单、明细、余额、库存、钱包、支付数据不变；不发送通知。覆盖非管理角色拒绝、管理角色可更新主订单及全部明细，以及五种详情页状态和管理配置的只读展示。

与钱包展示、钱包工作流、充值表单、门户会话隔离和商家首页性能测试共同执行：**104 项测试、1027 次断言全部通过**。报告位于工作区 `output/local-runtime/seller-order-permissions-verified-tests.xml`。生产 PHP 语法检查、Blade 预编译和 Git 差异空白检查通过。
